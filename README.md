# 🧊 Управление запасами холодильника (Fridge App)

Этот проект представляет собой консольное приложение на Python для управления списком продуктов на кухне. Программа позволяет добавлять продукты, искать их по названию, подсчитывать общее количество и отслеживать сроки годности.

## 🛠 Функционал

* **Добавление продуктов (`add`):** Позволяет добавить продукт с указанием количества и (опционально) даты истечения срока годности.
* **Парсинг заметок (`add_by_note`):** Удобная функция, которая принимает строку в формате списка покупок (например, `"Яблоки, 2"` или `"Молоко, 1.5, 2023-10-10"`) и автоматически разбирает её, добавляя товары в базу.
* **Поиск (`find`):** Ищет продукты по частичному совпадению названия (без учета регистра).
* **Подсчет количества (`amount`):** Суммирует количество определенного продукта в наличии (например, если у вас 2 партии молока, функция вернет общий объем).
* **Контроль сроков годности (`expire`):** Выводит список продуктов, срок годности которых истекает в ближайшие дни (или уже истек).

## 💻 Технологии

* **Python 3**
* **Модуль `datetime`** — для работы с датами и расчета сроков годности.
* **Модуль `decimal`** — для точного вычисления количества (чтобы избежать ошибок округления с числами с плавающей точкой, например, 0.5 кг).

## 🚀 Пример использования

```python
# Инициализируем словарь для хранения продуктов
goods = {}

# Добавляем продукты через функцию
add(goods, 'Пельмени Универсальные', Decimal('0.5'), '2025-03-20')

# Или с помощью удобного парсинга заметок
add_by_note(goods, 'Яблоки, 2')
add_by_note(goods, 'Молоко, 1.5, 2023-10-10')

# Ищем продукты
print(find(goods, 'ябл'))  # Вернет: ['Яблоки']

# Считаем общее количество
print(amount(goods, 'молоко'))  # Вернет: Decimal('1.5')
